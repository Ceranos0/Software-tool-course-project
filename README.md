# Software Tool Course Project

## Project Overview
This is a group project developed by three contributors exploring cybersecurity and web application development through a vulnerable Flask server and its security improvements.

## Team Contributions

- **Rolando ([@Ceranos0](https://github.com/Ceranos0))** - Pentesting & Vulnerability Analysis: Conducted security testing on a vulnerable Flask server, identifying and documenting security flaws

- **Jyoti ([@AlisterInn](https://github.com/AlisterInn))** - Developed a digital shopping place with patched vulnerabilities, implementing secure coding practices

- **Zidan ([@israkzidan450-source](https://github.com/israkzidan450-source))** - Created a login form 

## Project Structure
- `Rolando Vulnerability testing` - Original vulnerable Flask server implementation
- `Jyoti_feature_flask_server` - Enhanced version with security patches and e-commerce functionality

## Purpose
This project demonstrates the importance of secure coding practices and serves as a learning exercise in identifying, understanding, and fixing common web application vulnerabilities.
